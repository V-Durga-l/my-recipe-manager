🍳 Recipe Manager - Full Stack Web Application

🚀 Project Overview

A complete Flask web application for managing and sharing recipes

🔗 Live Application

Local Run Required (Flask Backend):

git clone https://github.com/V-Durga-l/my-recipe-manager.git
cd my-recipe-manager
pip install -r requirements.txt
python app.py
Open: http://localhost:5000
